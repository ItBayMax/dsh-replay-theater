## 三个公开函数

```ts
buildTimeline(records, options?) → Timeline     // records[] → 带绝对播放时刻的帧序列
frameIndexAt(timeline, atMs)     → number       // 二分定位（log n，供拖拽跳转）
stageAt(timeline, throughIndex)  → StageState   // 帧累积成可渲染的段落
```

**`buildTimeline` 接受任意 records 数组**，不绑定"当前会话"——这是为 v2 的并排对比和未来评测插件预留的接口。

## 核心算法：两阶段建帧

```text
阶段一：展开成"带绝对时间戳"的原始帧
  packed run → N 个成员帧，第 k 个的绝对时刻 = event.time + Σ max(0, dt[0..k-1])
  scalar     → 1 个 marker 帧，绝对时刻 = event.time

阶段二：按 seq 排序后，逐帧算相对播放时刻
  rel[0] = 0
  rel[i] = rel[i-1] + min(max(0, abs[i] - abs[i-1]), maxGapMs)
```

### 为什么分两阶段（而不是直接累加 dt）

**因为长静默既可能在 run 内部，也可能在 run 之间。**

只钳制 `dt[]` 的话，一个 step 结束到下一个 step 开始之间的静默（模型思考、用户离开几小时）会原样进入时间线，回放直接卡死。两阶段让**所有间隔走同一个钳制**——无论它来自 `dt[]` 还是来自两条记录的 `time` 差。

这条规则有专门的测试守着：

```ts
it('clamps the silence BETWEEN records, not only within a run', () => {
  const timeline = buildTimeline([
    textRun({ seq: 1, time: T0, texts: ['a', 'b'], dt: [10] }),
    textRun({ seq: 3, time: T0 + 120_000, texts: ['c', 'd'], dt: [10] }),  // 两分钟静默
  ], { maxGapMs: 1000 })
  expect(timeline.frames.map(f => f.atMs)).toEqual([0, 10, 1010, 1020])   // 被压到 1s
})
```

### 双重钳制的两个理由

```ts
const gap = Math.min(Math.max(0, rawGap), maxGapMs)
```

1. **`max(0, …)`**：上游明说 gap **可能为负**（`chunk-rows.ts:36-37`，墙上时钟回拨）。不钳制会让时间线倒流。
2. **`min(…, maxGapMs)`**：真实静默会让回放不可观看。默认 2000ms，可设 `Infinity` 取真实墙钟保真。

压缩不是静默发生的——`Timeline` 会报告 `compressedGaps`（压了几处）和 `compressedMs`（共压掉多少毫秒），UI 据此告知用户"长停顿已压缩"。**不隐瞒对数据的改动**是这个仓库一贯的姿态。

### 排序：seq 权威，时间戳不权威

调用方可能拼接多个窗口，所以建帧后按 `seq` 排序。**不按时间戳排**——时间戳可能回拨，而 seq 是上游保证连续的。

## 测试策略：为什么必须两套夹具

这是 P1 阶段最重要的发现，也修正了设计阶段的一个判断。

### 上游官方语料**不能**测节奏

实测全部 118 个 `snapshots/**/session.jsonl`：

- 快照做了**归一化**，`seq` 与 `time` 全部被剥掉（`snapshots/AGENTS.md`：*"Replace volatile identities with typed relationship-preserving tokens"*）→ 没有时间信息
- 快照跑的是 replay/mock 模型响应，回复极短——**全库最长的"连续同块 delta"只有 2 个成员**（逐文件扫描测得），而上游打包阈值是 3
- 最富的一份语料只有 3 个 `text-delta`

⚠️ **因此要修正设计文档里"118 个语料零 API key 即可演示"的说法**：语料可以验证**形状兼容性**，但**演示不了逐 token 打字效果**（token 太少）。真实的节奏演示需要跑一次真会话（要 API key），或用合成夹具。

### 两套夹具各司其职

| 夹具 | 覆盖什么 |
|---|---|
| `synthetic.ts`（手工） | **节奏逻辑**：精确 dt、负 dt、超长 gap、多 block、多 step、工具 run、空/单帧、dt 数组截断 |
| `corpus-escalation-approved.json`（派生） | **真实形状**：我们的 wire 类型镜像能吃真实事件；单调性、seq 严格递增、marker 类型不炸；**同时覆盖两条记录路径**（38 标量 + 1 打包） |

派生脚本 `make-corpus-fixture.mjs` 会重新赋 `seq`/合成 `time`，并按上游的 run-packing 规则打包（本地阈值降到 2，因为语料的连续 delta 最长就是 2）。脚本自身把这些取舍写在文件头注释里。
